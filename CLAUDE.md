# Regras do projeto

- Sempre que criar ou atualizar apresentações HTML (slides, decks, manuais), publicar automaticamente como Artefato usando a ferramenta Artifact. Isso garante que o conteúdo fique salvo com URL permanente.
- Sempre entregar os arquivos HTML prontos para download usando SendUserFile, para que a Fabi possa salvar e abrir direto no navegador.
